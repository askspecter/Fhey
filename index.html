// 00 what it is

      
Find the traders who are up. Resolve them to their real wallets. Read their positions and their reasoning. Watch every trade land in realtime. All from the command line, with every credit accounted for.

// 02 highlights

          
Built for traders who live in the terminal.

          

        

        

          

            01
            
            
Everything the API offers

            
Traders, positions, swaps, multi-chain portfolios, following and followers, spotlight, token flow, dev and insider positions, smart-money holders, theses, comment threads and search.

          

          

            02
            
            
Live ticker, zero credits

            
fomocli live streams the app feed, or the on-chain feed on Growth+, over a WebSocket with auto-reconnect. Streaming costs nothing.

          

          

            03
            
            
Full-screen dashboard

            
fomocli dash puts the leaderboard, token boards, the live feed and theses in one keyboard-driven TUI.

          

          

            04
            
            
Offline-first

            
Every response is cached on disk. --offline replays the last data you saw, and a dropped connection falls back to the cache on its own.

          

          

            05
            
            
Credit-aware

            
Every command shows what it cost and what is left. Expensive calls are labeled right in --help, and cache hits are free.

          

          

            06
            
            
Scriptable

            
--json on every command with clean stdout, meaningful exit codes, shell completion and FOMO_API_KEY.

// 05 offline mode

        
Your data. Even when the wifi isn't.

      

      
    
        
  1. 
          01
          
    Repeat for free
    
          
    A command repeated inside the cache TTL (default 60s) is served from disk for 0 credits. Skip it with --fresh.
    
        
    2. 
        
  2. 
          02
          
    Automatic fallback
    
          
    If the network drops, fomocli shows the cached copy and tells you how old it is.
    
        
    3. 
        
  3. 
          03
          
    Explicit offline
    
          
    --offline or FOMO_OFFLINE=1 never touches the network. Even live --offline replays recorded events.
    
        
    4. 
      

      

        

          
offline


fomocli lb --offline                       # last leaderboard you loaded
fomocli t CryptoKaleo positions --offline  # last positions
fomocli live --offline -n 50               # replay 50 live events
fomocli cache ls                           # what's available offline

        

        

          
scripting


# Top 10 by volume as CSV
fomocli lb 7d --json | jq -r '.traders | sort_by(-.volumeUsd)[:10][] | [.handle, .volumeUsd] | @csv'

# Every whale buy on Robinhood Chain
fomocli live --chain robinhood --min-usd 25000 --json | jq -c '{trader, token, usdValue}'
